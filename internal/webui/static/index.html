Accounts

Each account is an Immich user on a server. The app keeps an upload-only key for it in your system's keychain.

Watched folders

Photos and videos added to these folders are uploaded to the chosen account. Deleting a file here never deletes it in Immich.

Upload timing

A new file is uploaded once it has been left unchanged this long. If you delete or move it before then, it isn't uploaded, so a longer wait gives you time to undo a file put in by mistake.

New files are normally noticed right away. This extra check catches anything missed, for example on network drives.
